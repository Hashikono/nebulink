To extract a password-protected file from a 7-Zip archive, right-click the file, select 7-Zip > Extract Here or Extract files..., and enter the correct password when prompted, which will then decrypt and extract the file to your chosen location. 
Step-by-step instructions: 
- Locate: the password-protected archive file you want to extract.
- Right-click: the file.
- Hover over: the 7-Zip option in the context menu.
- Select: either Extract Here to extract the files to the same folder as the archive, or Extract files... to choose a different destination folder.
- Enter the password: in the password prompt dialog box.
- Click: OK.
